# খবর এক নজরে (সংস্করণ ১ – বিজ্ঞাপনহীন)

বাংলাদেশ ও বিশ্বের খবর এক জায়গায়। অ্যাপ বিভিন্ন সংবাদমাধ্যমের প্রকাশ্য RSS ফিড থেকে শুধু
শিরোনাম, ছোট সারাংশ ও লিংক আনে। পুরো খবর পড়তে চাপলে মূল সাইট খোলে। খবরের লেখা কপি করা হয় না।

> অবস্থা: কোড লেখা হয়েছে, কিন্তু লেখক এটি কম্পাইল বা ফোনে চালিয়ে দেখেননি।
> প্রথম GitHub বিল্ডে ভুল আসতে পারে। ভুলের লেখা পাঠালে ঠিক করে দেওয়া হবে।

## যা আছে
- দুটি প্রধান ট্যাব: বাংলাদেশ, বিশ্ব। সাথে ফ্যাক্ট চেক, সেভ করা, সেটিংস।
- একই ঘটনার খবর একটি কার্ডে। ভেতরে কোন কোন সূত্র লিখেছে তার তালিকা ও লিংক।
- চিহ্ন: ৩+ সূত্র = "বহু সূত্রে নিশ্চিত", ২টি = "২টি সূত্রে", ১টি = "একক সূত্র"।
  **এটি কতজন প্রকাশ করেছে তা দেখায়, সত্যের প্রমাণ নয়।**
- ব্যাকগ্রাউন্ডে ৩০ মিনিট / ১ ঘণ্টা / ৩ ঘণ্টা পর পর খবর আনা (শুধু ইন্টারনেট থাকলে)।
- অফলাইনে শেষবার আনা ৩ দিনের খবর পড়া যায়।
- বড় খবরের নোটিফিকেশন (৩ ঘণ্টায় ৪+ সূত্রে এলে, ঐচ্ছিক)।
- সেভ ও শেয়ার।
- কোনো ব্যক্তিগত তথ্য সংগ্রহ হয় না।

## এখনো নেই (পরের ধাপ)
1. ধাপ ২: Firebase দিয়ে লাইভ ইউজার, জনপ্রিয় খবর, ক্র্যাশ রিপোর্ট, লাইক, "ভুল খবর জানান", দূর থেকে সূত্র বদল।
2. ধাপ ৩: বিজ্ঞাপন এবং ঐচ্ছিক সাবস্ক্রিপশন।
3. ক্যাটাগরি (রাজনীতি, খেলা ইত্যাদি)।

## সূত্র বদলানো (কোড না জেনেই)
GitHub-এ `app/src/main/assets/sources.json` খুলে পেন্সিল (✏️) চাপুন। প্রতিটি লাইন একটি সূত্র:
`id`, `name` (অ্যাপে যে নাম দেখাবে), `region` (`bd`, `world` বা `both`), `kind` (`news` বা `factcheck`), `url` (RSS ঠিকানা)।
বদলে Commit করলে নতুন APK বিল্ড হবে।

**গুরুত্বপূর্ণ:** অনেক বাংলাদেশি সাইটের ফিডের ঠিকানা যাচাই করা যায়নি। অ্যাপ খুলে
সেটিংস > "সূত্রের অবস্থা" দেখুন কোনটি "ব্যর্থ"। সেগুলোর সঠিক ঠিকানা খুঁজে বদলাতে হবে বা বাদ দিতে হবে।
